生命徵象監測 / Vital Signs

請勾選需定期監測的生命徵象項目（固定照顧計劃項目，非每日數值記錄）/ Select vital signs to monitor regularly

💨 血氧 SpO₂

🩸mmHg
✓
正常範圍：收縮壓 90–139 mmHg，舒張壓 60–89 mmHg
Normal: Systolic 90–139 / Diastolic 60–89 mmHg
⚠ 量測注意事項 ▼
  • 量測前靜坐休息5分鐘，勿說話或活動
  • 手臂自然放平，袖帶綁在肘關節上2 cm，鬆緊以塞入兩指為準
  • 手臂應與心臟同高；袖帶不可綁在有輸液或動靜脈廔管的手臂
  • 飯後、運動後、泡澡後30分鐘內不宜量測
  • 左右手各量一次，記錄數值較高側作為基準
⚠ 收縮壓 >160 或 <90 mmHg 請立即通報家屬
💓次/min
✓
正常範圍：60–100 次/分
Normal: 60–100 beats/min
⚠ 量測注意事項 ▼
  • 量測前靜坐休息5分鐘
  • 以食指、中指輕壓手腕橈動脈（拇指側內側），勿使用拇指
  • 完整計數1分鐘，同時注意節律是否規則
  • 若使用血壓計，機器同步顯示脈搏時以機器數值為準
⚠ 脈搏 <50 或 >120 次/分，或節律不規則，請立即通報
🌡°C
✓
正常範圍：腋溫 36.1–37.2°C，耳溫 35.8–37.8°C
Normal: Axillary 36.1–37.2°C / Ear 35.8–37.8°C
⚠ 量測注意事項 ▼
  • 腋溫：擦乾腋窩汗水，夾緊體溫計量7分鐘，正常 36.1–37.2°C
  • 耳溫：輕拉耳廓向後上方使耳道伸直，探頭對準耳膜，正常 35.8–37.8°C
  • 額溫：距額頭2–3 cm平掃，避免有汗水或帽子
  • 飯後、運動後、泡澡後30分鐘內不宜量測
⚠ ≥38°C 為發燒、<35°C 為低體溫，請立即通報家屬
💨%
✓
正常範圍：95–100 %（<95% 需密切觀察）
Normal: 95–100 % (<95% needs close monitoring)
⚠ 量測注意事項 ▼
  • 夾在食指或中指，指甲朝上；指甲不可塗深色指甲油
  • 手指過冷時先搓熱，或用溫毛巾敷後再測
  • 量測時手指保持靜止不動，等待數值穩定（約10秒）再讀數
  • 剛量完血壓或穿刺側的手指暫時不用
⚠ SpO₂ <95% 需密切觀察；<90% 請立即叫救護車
🌬次/min
✓
正常範圍：12–20 次/分（老人可至 25）
Normal: 12–20 breaths/min (elderly up to 25)
⚠ 量測注意事項 ▼
  • 勿告知受照顧者正在量測呼吸（避免刻意改變呼吸頻率）
  • 觀察胸腹部起伏，一起一伏算一次，計數1分鐘
  • 注意呼吸是否費力、有無喘鳴聲、呼吸深淺是否均勻
  • 可在量完脈搏後繼續觀察呼吸（被照顧者以為還在測脈搏）
⚠ 呼吸 <10 或 >30 次/分，或呼吸困難費力，請立即通報
🍬mg/dL
✓
正常範圍：空腹 70–100 mg/dL，飯後2h <140 mg/dL
Normal: Fasting 70–100 / Post-meal 2h <140 mg/dL
⚠ 量測注意事項 ▼
  • 以酒精棉片擦拭指尖，待完全乾燥後再穿刺（酒精殘留影響數值）
  • 穿刺指尖側面（非正中），輪替不同手指，避免慣用手拇指
  • 第一滴血擦掉，用第二滴血測試；不可擠壓手指（組織液稀釋影響準確性）
  • 記錄量測時間點（飯前 / 飯後2小時），並記入血糖記錄表
  • 試紙注意有效期限及開瓶日期，存放於乾燥陰涼處
⚠ 血糖 <70 mg/dL 低血糖（緊急處置）；>300 mg/dL 高血糖（立即通報就醫）
